# Collaborate with Daniel Khan

This is the public, moderated space for working with me on research, documentary projects and open tools. My portfolio is at **https://danielkhan.org**.

## Ways to take part

| You want to… | Go to |
|---|---|
| **Join an existing project** | [Offer to help](https://github.com/DANIELKHAN26/collaborate/issues/new?template=join-a-project.yml), or use the button on any project page on the [collaborate page](https://danielkhan.org/collaborate/) |
| **Suggest an idea or ask a question** | [Discussions → Ideas / Q&A](https://github.com/DANIELKHAN26/collaborate/discussions) |
| **Share something you built with a workshop resource** | [Discussions → Show and tell](https://github.com/DANIELKHAN26/collaborate/discussions/categories/show-and-tell) |
| **Report an error on the site** | [Suggest a correction](https://github.com/DANIELKHAN26/collaborate/issues/new?template=correction.yml) |
| **Report a bug in a tool** | [Tool issue](https://github.com/DANIELKHAN26/collaborate/issues/new?template=tool-issue.yml) |
| **Write privately** | Email [hello@danielkhan.org](mailto:hello@danielkhan.org) |

## Before you post

Everything here is **public** and may be indexed by search engines. Don't post passwords, private documents, unpublished interviews, or anything that identifies research participants. For anything sensitive, ask for a private channel.

Read the [contributing guide](CONTRIBUTING.md) and the [code of conduct](CODE_OF_CONDUCT.md).
